# 💪 Mi rutina

Webapp de un solo archivo (`index.html`) para cargar la rutina de gimnasio desde el celular.

- Días A / B / C con superseries y prevención
- Kg y reps por semana (semanas 1 a 6)
- Se guarda solo en el navegador (localStorage), sin backend
- Botones: traer datos de la semana anterior, respaldo y carga JSON

## Cómo usarla

1. Abrí la URL publicada en el celular
2. "Agregar a pantalla de inicio" para que quede como app
3. Los datos viven en el navegador del teléfono: usá **Respaldo** para exportar un JSON y **Cargar** para restaurarlo

## Publicar (GitHub Pages)

Repo → Settings → Pages → Source: `main` / raíz. La app queda en `https://USUARIO.github.io/rutina/`.
